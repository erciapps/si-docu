# Práctica 4 Parte I. Publicación de servicios web en Docker mediante DNS local y proxy inverso Nginx

## 1. Título
Configuración de un servidor DNS local y de un proxy inverso Nginx para publicar varios servicios web alojados en contenedores Docker en una misma máquina, accediendo a cada uno mediante un nombre de host distinto.

## 2. Resultado de aprendizaje y criterios de evaluación

### RA5. Interconecta sistemas en red configurando dispositivos y protocolos
- **a)** Se ha configurado el protocolo TCP/IP.
- **f)** Se han gestionado puertos de comunicaciones.
- **g)** Se ha verificado el funcionamiento de la red mediante el uso de comandos y herramientas básicas.

### RA6. Opera sistemas en red gestionando sus recursos e identificando las restricciones de seguridad existentes
- **c)** Se han explotado servidores de ficheros, servidores de impresión y servidores de aplicaciones.

## 3. Objetivos de la práctica
- Configurar la resolución DNS local para asociar varios nombres de host a una misma dirección IP.
- Desplegar varios servicios web en contenedores Docker dentro de una misma máquina.
- Configurar Nginx como proxy inverso para publicar esos servicios mediante distintos nombres de host.
- Verificar el funcionamiento de la publicación web utilizando herramientas de red y navegador.
- Distinguir el papel del DNS, del proxy inverso y de los contenedores en el acceso a un servicio web.
