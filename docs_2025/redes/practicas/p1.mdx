# Práctica 1. Configuración de una LAN en un router con DHCP y verificación desde Windows

## 1. Título
Configuración básica de una red de área local en un router: direccionamiento LAN, servicio DHCP, configuración estática y comprobación de conectividad desde un cliente Windows.

## 2. Contexto de la práctica
En esta práctica, cada pareja trabajará sobre un router accesible de forma remota mediante **SSH**. El router dispone de una interfaz **WAN** previamente configurada con **IP estática** y conectividad exterior operativa. A partir de esa configuración base, el alumnado deberá preparar la red **LAN** del router, definiendo una dirección de red, una máscara y un rango de direcciones dinámicas para el servicio **DHCP**.

Una vez realizada la configuración remota, la pareja acudirá físicamente al router para conectar un equipo cliente con **Windows** a la LAN y verificar el funcionamiento de la red. Primero comprobará la obtención automática de parámetros mediante DHCP. Después configurará manualmente una dirección IP estática válida y volverá a realizar las comprobaciones oportunas.

La práctica permite trabajar de forma integrada el direccionamiento IP, la máscara de subred, la puerta de enlace, el servicio DHCP y el uso de comandos básicos de diagnóstico en Windows.

## 4. Objetivos didácticos
Al finalizar la práctica, el alumnado deberá ser capaz de:
- Configurar correctamente la interfaz LAN de un router.
- Definir una red, una máscara y un rango válido de direcciones para clientes.
- Configurar un servicio DHCP básico en la red local.
- Comprobar la obtención automática de parámetros de red desde un cliente Windows.
- Configurar manualmente una dirección IP estática válida en el cliente.
- Verificar conectividad con la puerta de enlace, con Internet y con servicios de resolución de nombres.
- Interpretar el resultado de comandos básicos de diagnóstico de red.
- Documentar el procedimiento técnico seguido y justificar las decisiones tomadas.

## 5. Recursos necesarios
- 1 router por pareja con acceso remoto por **SSH**.
- Interfaz **WAN** del router previamente operativa.
- Interfaz **LAN** disponible para la práctica.
- 1 equipo cliente con **Windows**.
- Cable de red para conectar el cliente al router.
- Credenciales de acceso al router.
- Documento digital para la entrega.

## 7. Desarrollo de la práctica

### Parte 1. Acceso remoto al router
1. Conectarse por **SSH** al router asignado.
2. Identificar la configuración actual del equipo.
3. Verificar qué interfaz corresponde a la **LAN** y cuál a la **WAN**.
4. No modificar la configuración de la WAN salvo indicación expresa.

### Parte 2. Configuración de la LAN en el router
Configurar la interfaz LAN con los datos asignados por el profesor.

La configuración mínima deberá incluir:
- Dirección IP LAN del router.
- Máscara o prefijo de red.
- Activación de la interfaz LAN, si procede.

El alumnado deberá dejar reflejado en la entrega:
- Dirección de red.
- Máscara en decimal y en notación CIDR.
- Primera IP utilizable.
- Última IP utilizable.
- Dirección de difusión.
- Número de hosts válidos.

### Parte 3. Configuración del servicio DHCP
Sobre la interfaz LAN configurada, habilitar un servicio DHCP con los siguientes parámetros:
- Rango de direcciones asignables.
- Máscara entregada a los clientes.
- Puerta de enlace entregada a los clientes.

Se recomienda dejar fuera del rango DHCP algunas direcciones para posibles configuraciones estáticas.

### Parte 4. Conexión del cliente Windows y comprobación en modo automático
1. Acudir al router físicamente.
2. Conectar el equipo Windows a la interfaz LAN del router.
3. Configurar la tarjeta de red del cliente en obtención automática.
4. Renovar la concesión DHCP si fuera necesario.
5. Comprobar los parámetros recibidos.

#### Comandos orientativos en Windows
```bat
ipconfig
ipconfig /all
ipconfig /release
ipconfig /renew
```

### Parte 5. Verificación de conectividad en modo DHCP
Con la IP obtenida automáticamente, realizar y documentar al menos las siguientes comprobaciones:

1. Comprobación de la configuración IP del cliente.
2. Conectividad con la puerta de enlace.
3. Conectividad con una IP pública.
4. Comprobación de resolución de nombres.
5. Observación de la ruta seguida o de la tabla de rutas, si se solicita.

#### Comandos orientativos en Windows
```bat
ping <IP_LAN_DEL_ROUTER>
ping 8.8.8.8
ping google.com
nslookup google.com
tracert 8.8.8.8
route print
arp -a
```

### Parte 6. Configuración manual de IP estática en el cliente Windows
1. Cambiar la configuración del adaptador de red de automática a manual.
2. Asignar una IP estática válida dentro de la red LAN.
3. Comprobar que esa IP no pertenece al rango DHCP definido.
4. Introducir correctamente la máscara, la puerta de enlace y el DNS.

### Requisitos de la IP estática
- Debe pertenecer a la misma red que la LAN del router.
- No puede ser la dirección de red ni la de difusión.
- No debe coincidir con la IP de la puerta de enlace.
- No debe estar dentro del rango DHCP si se quiere evitar conflicto de direcciones.

### Parte 7. Verificación de conectividad en modo estático
Repetir las mismas comprobaciones realizadas en modo DHCP:
- Mostrar la configuración del equipo.
- Verificar conectividad con la puerta de enlace.
- Verificar salida a Internet mediante IP.
- Verificar resolución de nombres.

#### Comandos orientativos en Windows
```bat
ipconfig /all
ping <IP_LAN_DEL_ROUTER>
ping 8.8.8.8
ping google.com
nslookup google.com
```

### Parte 8. Análisis y reflexión
Responder brevemente a las siguientes cuestiones:
1. ¿Qué parámetros ha recibido el equipo automáticamente mediante DHCP?
2. ¿Qué diferencias hay entre la configuración automática y la manual?
3. ¿Por qué es recomendable elegir una IP estática fuera del rango DHCP?
4. ¿Qué ocurriría si la puerta de enlace estuviera mal configurada?
5. ¿Qué ocurriría si el DNS fuera incorrecto pero hubiera conectividad IP?
6. ¿Qué ocurriría si la IP estática elegida no perteneciera a la red LAN configurada?

## 8. Entrega
La entrega deberá incluir, como mínimo:

1. **Guía de configuración** realizada el equipo, explicando de forma ordenada lo que se ha configurado en el router.
2. **Datos de direccionamiento** utilizados: red, máscara, IP LAN del router, rango DHCP, DNS e IP estática elegida para el cliente.
3. **Justificación** de que la IP estática elegida es válida y está fuera del rango DHCP.
4. **Capturas o evidencias** de los comandos ejecutados en Windows, al menos en modo DHCP y en modo estático.
5. **Resultados de las pruebas** de conectividad:
   - hacia la puerta de enlace,
   - hacia una IP pública,
   - hacia un nombre de dominio.
6. **Relación de comandos usados** y breve explicación de para qué sirve cada uno.
7. **Incidencias encontradas** y cómo se resolvieron.
8. **Conclusiones finales** sobre el funcionamiento de la red.

## Posibles incidencias para trabajar en clase
Durante la práctica o como ampliación, se puede provocar o analizar alguno de estos errores:
- Máscara incorrecta en el cliente.
- Puerta de enlace incorrecta.
- DNS incorrecto.
- IP estática dentro del rango DHCP.
- IP estática fuera de la red configurada.
- Rango DHCP mal definido o insuficiente.
- Cable conectado a una interfaz incorrecta.
